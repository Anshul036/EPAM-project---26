# Assignment 1: XYZ Bank Customer Page

A JavaScript implementation for XYZ Bank's Diwali coupon feature.

---

## 🎯 Key Features

* **Welcome Alert:** Displays a popup message (`Welcome to XYZ bank !!!`) when hovering over the welcome text.
* **Hide Instructions:** Hides the step-by-step instructions dynamically upon clicking **Register**.
* **Coupon Generation:** Validates if the Customer ID contains `XYZ` and appends `789456` to generate a unique coupon code.

---

## 📂 File Included

* `index.html` — Source code containing HTML structure and JavaScript logic.

---

## 🚀 How to Run

1. Open `index.html` in any browser.
2. Hover over **"Welcome customer !!!"** to view the greeting.
3. Click **"Click here to Register"** to hide the setup steps.
4. Enter a Customer ID (e.g., `XYZ101`) and click **Validate customer** / **Generate coupon**.
